# Copa Mandatín

Juego escolar de eliminación para 2 a 64 participantes. La pantalla de inicio usa a Mandatín, el personaje azul de cuerpo completo, en una arena escolar espacial. Los nombres de los participantes se muestran grandes para la sala de clases.

Abre `index.html` en un navegador o publica esta carpeta en GitHub Pages. No necesita dependencias ni servidor.

1. Pulsa **Nueva copa**. Sube una lista TXT/CSV (primera columna, un nombre por fila) o pega los nombres.
2. Elige la dinámica y sortea el fixture. Los pases directos completan las llaves cuando el número de participantes no es potencia de dos.
3. Después de cada dinámica, el docente selecciona al ganador. El resultado avanza a la siguiente ronda. Hay efectos para el ganador, reconocimiento para quien termina su participación y celebración del campeón.
4. Pulsa **Menú** para ver **Mis copas guardadas** y **Continuar** cuando retomes la clase.

Se pueden guardar varias copas. Cada cambio se guarda automáticamente en el navegador; **Guardar** fuerza otro guardado. **Exportar** descarga un archivo JSON de la copa y **Cargar archivo** lo recupera en otro navegador o dispositivo. Borrar datos del navegador elimina los guardados locales, por lo que conviene exportar las copas importantes. Los nombres no se envían a un servidor.

Admite listas CSV separadas por coma, punto y coma o tabulación. Para Excel, exporta la lista a CSV. Incluye deshacer, modo pantalla completa, sonido opcional y respeto a movimiento reducido.
